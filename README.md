# sahana-mind-matrix
NALLA NUDI PROJECT
Nalla-Nudi – Technical Dictionary App

Nalla-Nudi is an Android application developed to help Kannada-medium students understand technical English terms easily. The app provides simple Kannada meanings, pronunciation support, and subject-wise filtering for educational terms related to Science, Mathematics, and Commerce.

Key Features
Technical term search with Kannada explanations
English pronunciation using Text-to-Speech
Subject-wise filtering
Offline access using Room Database
“My List” feature for revision and flashcards

Technologies Used

Android Studio
Java/Kotlin
Room Database
Text-to-Speech (TTS)
XML UI Design

Objective
The main goal of this project is to reduce language barriers for rural students and improve confidence in technical education.
